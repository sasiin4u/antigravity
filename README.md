# Snowflake Quickstarts & GitHub Project

This repository tracks progress on various [Snowflake Quickstarts](https://quickstarts.snowflake.com/) and serves as a portfolio of data engineering projects.

## Goals

1.  **Snowflake Quickstarts**: Hands-on practice with Snowflake features (Zero to Snowflake, Data Warehousing, Data Engineering, etc.).
2.  **GitHub**: Version control and tracking of project progress.
3.  **Future**: Integration with dbt for transformation workflows.

## Structure

- `snowflake-quickstarts/`: Contains specific labs and sub-projects from Snowflake guides.

## Getting Started

Check out the folders for individual project documentation.
